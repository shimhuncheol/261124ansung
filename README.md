- 연수 페이지: https://shimhuncheol.github.io/261124ansung/

- 원본 공문은 K-에듀파인에서 비공개로 지정된 문서입니다. 공개 저장소에 올리기 전에 게시해도 되는지 확인하세요.

- 5단계 업무 웹앱 실습은 [차곡](https://shimhuncheol.github.io/chagok/)을 씁니다. 누구나 무료로 쓸 수 있습니다.

## 참여 결과 연결하기 (처음 한 번, 약 3분)

퀴즈 결과와 '해볼 업무'는 구글 시트에 모이고, 발표자 화면의 **결과** 버튼(R)에서 실시간으로 볼 수 있습니다.

1. 구글 시트를 새로 만듭니다. (주소창에 `sheets.new`)
2. 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 통째로 붙여넣은 뒤 저장합니다.
4. 오른쪽 위 **배포 → 새 배포**를 누르고, 유형은 **웹 앱**을 고릅니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. **배포**를 누르고 권한을 허용하면 `https://script.google.com/macros/s/.../exec` 주소가 나옵니다.
6. 이 저장소의 `config.js`를 열어 `api: ""` 따옴표 안에 그 주소를 붙여넣고 저장(커밋)합니다.

1~2분 뒤 연수 페이지를 새로고침하면 연결됩니다. 시트에는 `퀴즈`, `해볼업무` 탭이 자동으로 생깁니다.

- 연수 회차를 나누려면 `config.js`의 `session` 값을 바꾸세요.
- 발표자 화면의 결과 창에서 **지금부터 새로 집계**를 누르면 그 시각 이후 결과만 보입니다.
- 참여자 이름은 '이름 또는 학교'로 받습니다. 결과 창의 **이름 가리기**로 화면에서 이름을 숨길 수 있습니다.
