# 2026 안성 AI 디지털 기반 교육혁신 학교관리자 직무연수 · 실습 키트

안성지역 교감·교장 대상 AI 연수 실습 페이지입니다. 16:9 발표 화면으로 만들었고, 참여자도 같은 주소로 들어와 실습합니다.

- 연수 페이지: https://shimhuncheol.github.io/261124ansung/
- 실습 공문은 K-에듀파인 「2027.3.1.자 공립 유·초등교원 시·도간 교류 추진 계획」 본문이며, 담당자 이름은 ○○○으로 가렸습니다. 현황판의 교사 이름은 가상입니다.
- 원본 공문은 K-에듀파인에서 비공개로 지정된 문서입니다. 공개 저장소에 올리기 전에 게시해도 되는지 확인하세요.

- 5단계 업무 웹앱 실습은 [차곡](https://shimhuncheol.github.io/chagok/)을 씁니다. 누구나 무료로 쓸 수 있습니다.

## 참여 결과 연결하기 (처음 한 번, 약 3분)

퀴즈 답과 '해볼 업무'는 구글 시트 **「2026 안성 학교관리자 직무연수 · 참여 결과」**에 실시간으로 쌓입니다.

| 탭 | 내용 |
|---|---|
| 실시간 점수판 | 참여 인원·평균·만점자, 이름별 ○/×, 점수 순위 (1~3위 강조) |
| 문항별 정답률 | 문항마다 응답 수·맞힌 사람·정답률, 막대 그래프 |
| 퀴즈기록 | 답을 누를 때마다 한 줄씩 쌓이는 원본 기록 |
| 해볼업무 | 마무리 장에서 제출한 내용 |
| 집계 | 점수판 계산용 (손대지 않기) |

같은 문제를 다시 풀면 마지막 답으로 계산됩니다.

1. 시트를 열고 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
2. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 통째로 붙여넣은 뒤 저장합니다.
3. (리허설) 함수 목록에서 `시연데이터넣기`를 골라 **실행**하면 가상 8명의 결과로 점수판이 채워집니다. 연수 전에는 `기록지우기`를 실행해 비웁니다.
4. **배포 → 새 배포 → 웹 앱**: 실행 사용자 **나**, 액세스 권한 **모든 사용자** → 배포 → 권한 허용
5. 나온 `https://script.google.com/macros/s/.../exec` 주소를 `config.js`의 `api: ""` 안에 넣고 커밋합니다.

- 학교(기관) 구글 계정에서 '모든 사용자'가 보이지 않으면 관리자가 외부 공개를 막아 둔 것입니다. 이때는 개인 구글 계정으로 시트를 복사해 같은 방법으로 배포하세요.
- 연수 페이지 17번 장 **실시간 결과**에서 누구나 점수·정답률·순위를 볼 수 있고, **결과 시트 바로 가기** 버튼으로 시트(보기 전용)도 열 수 있습니다.
- 연수 중에는 시트의 **실시간 점수판** 탭을 화면에 띄우면 참여자가 답할 때마다 점수와 순위가 바뀌는 모습을 보여줄 수 있습니다. 발표 페이지의 **결과**(R) 버튼에서도 같은 결과를 볼 수 있습니다.
